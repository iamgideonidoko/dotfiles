# dotfiles

Personal macOS and Omarchy dotfiles.

## Clone

```sh
git clone git@github.com:iamgideonidoko/dotfiles.git ~/dotfiles
cd ~/dotfiles
```

## macOS

![macOS workspace preview](./preview-macos.jpg)

```sh
make macos-setup
```

## Omarchy

![Omarchy workspace preview](./preview-omarchy.jpg)

```sh
make omarchy-setup
```
